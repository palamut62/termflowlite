Read a long session at a glance

Shell integration marks every command in PowerShell, Git Bash, bash and zsh. A green line means it passed, red means it failed, and slow commands show how long they took.

  • Ctrl ↑ and Ctrl ↓ jump between commands in a long scrollback
  • Right-click a command to copy its output, rerun it or copy it ready for an AI agent
  • A command that runs for more than 10 seconds in a background tab sends a notification when it ends

Run agents and shells side by side

Split the window, drag panes to re-tile them and keep Claude Code, Codex or OpenCode next to the shell that runs your tests.

  • Give each agent its own git worktree so parallel sessions never overwrite each other
  • Hand work from one agent or provider to another without losing the context
  • Tabs show live state: running, waiting for input, new output, done or failed
  • Agent Memory keeps a short memory of each project from your last 30 days of sessions, so the next agent continues where the last one stopped

Take your terminal to your phone

Turn on Remote Access, scan a QR code once and your phone controls TermFlow Lite on your computer over Tailscale. Step away while an agent works and keep an eye on it from anywhere.

  • Every tab streams live, line by line, and tapping it opens the keyboard. The phone mirrors the desktop terminal without squeezing it; tap Fit to size a tab to the phone
  • Open and close tabs, start any shell, agent, provider or SSH connection, resume agent sessions and run saved commands
  • Change settings, profiles, providers and SSH connections from the phone; the computer picks them up at once
  • Listens only on your Tailscale address, never on the local network or the internet. Pair by scanning the QR from the phone app, even from the home screen; it stays paired until you disconnect it
  • See and control the whole computer, not just the terminal: the Screen tab shows your desktop on the phone, sign-in screen and UAC prompts included. Touch moves the mouse, the phone keyboard types, and turning the phone sideways fills its screen. It needs a VNC server running as a service on the computer; TermFlow reaches it there and never opens it to the network

Talk instead of typing

Hold Space and speak, let go and the text appears at the cursor, cleaned up and ready for you to check before pressing Enter. A short press is still a space. For longer requests press Ctrl Shift Space once and just talk: it stops when you pause.

  • Punctuation and spelling fixed, filler words removed, commands and file names written the way you type them
  • Knows where you are: commands at a shell prompt, requests in Claude Code, Codex and OpenCode
  • Turkish and English, with an OpenRouter model of your choice and your own key; ten seconds of speech cost about a hundredth of a cent
  • Off until you turn it on; nothing is recorded unless you hold Space or press Ctrl+Shift+Space, and Esc cancels
  • In agent tabs, end with "send" and Enter is pressed for you; add your own names and terms so they are spelled right

Every agent on your PC, ready to go

TermFlow Lite finds the agent CLIs you have installed and adds each one to the New Tab menu with its full-access flag. Install a new one and it shows up by itself.

  • Claude Code, Codex, OpenCode, Gemini CLI, Qwen Code, Copilot CLI, Grok, Droid, Kimi, Pi and more, only when they are installed
  • The same list in the Explorer right-click menu and on your phone
  • Know which tab needs you: a coloured dot, a bell with a count, a taskbar badge, a notification and a sound, driven by the agent's own hooks. Jump to it with Ctrl Shift J
  • Reopen the app and every tab comes back with its output and its Claude or Codex conversation. Claude and Codex limits show in the status bar
  • Agent CLIs installed with npm update themselves in the background at start and once a day; each profile shows its version
  • Watch Claude Code's background shell tasks and subagents live, each in its own tab: click the count on the tab

New: a separate app

TermFlow Agent IDE: a workspace for your coding agents

The same terminal with your projects around it. Every worktree and the agents working in it in one sidebar, and the code they changed one click away.

  • Projects, git worktrees and agent sessions with their live state: working, needs you, done. Group by status or pull request, or open the board
  • Start a worktree from a branch, #123 or a pull request link and pick the agent that works in it
  • Review the diff, comment on lines and send every comment to the agent as one message
  • Source control, pull request checks, GitHub tasks and notes per worktree. Ctrl Shift I switches to a plain terminal
  • Orchestration: your agent hands mechanical work to another installed agent (OpenCode, Codex, Grok, Claude Code, Antigravity, Gemini CLI, Qwen Code, Copilot CLI, Kimi, Droid), each in its own worktree, then reviews and applies the result
  • The project menu in the sidebar opens any agent profile (Claude Code, Codex...) right in that folder

Type less, find more

Commands you ran before appear as a grey suggestion while you type. Press → to take it.

  • Compiler and test errors like src/app.ts:42:7 open at that line in VS Code, Cursor or Windsurf
  • Search every command you ran with Ctrl Shift H
  • Run package.json scripts, Git and Docker tasks from the palette with Ctrl Shift P
  • Double-click a word in the line you are typing and type over it. The cursor stays where you are, in the shell and in Claude Code or Codex. Triple-click and press Delete to clear the whole line

See the screenshots your tools save

When an agent, a test run or a script saves an image or a video in your project, a preview card shows up in the corner of the terminal. Drop or paste a file and you get the same card.

  • Cards fold into small thumbnails in the info strip so nothing piles up
  • Click one to view it full size or play the video, open it, show it in its folder, or insert its path for your agent
  • Video thumbnails come from Windows itself, no ffmpeg needed, and nothing leaves your machine
  • Copied a screenshot or an image from the browser? Paste it and TermFlow saves it as a PNG and inserts its path, ready for Claude Code or Codex

Make it feel like yours

Fifteen themes and a custom palette editor, Mica and Acrylic backdrops on Windows 11, cursor trails and an optional retro CRT screen. Motion can be subtle, full or off, and the system reduce-motion setting always wins.

  • WebGL rendering, ligatures and inline images (Sixel and iTerm2)
  • Mechanical or soft key sounds, and confetti when your tests pass, if you want them
  • Give a profile a picture and it is drawn in dots, letters or blocks behind your text, at the density and opacity you pick

See your year in the terminal

Wrapped counts your commands, top tools, busiest hour and streaks, and hands out badges like Night Owl and Commit Machine. It is drawn like terminal output, in your terminal font and theme colors. Save it as an image to share.

Wrapped stores counters and tool names only, never arguments or output, and nothing leaves your machine.
